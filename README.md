# if조선 — 웹 데모

광해군이 되어 **폐모살제 · 강홍립 파병 · 인조반정**을 헤쳐 나가는
조선왕조 시뮬레이션. 한 판에 약 3분.

> 가로 화면 전용입니다. 세로로 잡으면 회전 안내가 뜹니다.

---

## 무엇을 하는 게임인가

체력 · 재정 · 평판 세 수치와 신하 3인의 충성도를 관리하면서
15년 치세의 분기점 세 개를 넘깁니다.

**핵심은 잠긴 선택지입니다.** 조건을 못 채운 선택지를 숨기지 않고
회색으로 보여주면서 필요한 수치까지 같이 적어 둡니다.
"저걸 고르려면 무엇이 모자랐는가"가 그 자리에서 보이는 게 이 게임의 장치입니다.

정무 단계에서 뽑히는 사건은 7종 중 매번 무작위 5개라,
회차마다 열리는 선택지가 달라집니다.

### 엔딩 4종

| 엔딩 | 조건 |
| :--- | :--- |
| 줄 위의 치세 | 반정 저지 + 중립외교 밀지 + 평판 55 이상 |
| 칼 위의 옥좌 | 반정 저지 (그 외) |
| 묘호 없는 왕 | 반정 실패 (사실대로) |
| 하늘이 버린 왕 | 반정 실패 + 평판 35 미만 |

## 구조

```
index.html     화면 뼈대
style.css      스타일
game.js        스크립트 데이터 + 진행 엔진
assets/        배경 8 · 인물 9 · 로고 (WebP, 약 1.7MB)
```

빌드 과정이 없습니다. 정적 파일 그대로 올리면 동작합니다.

`game.js` 안에서

- `SEQ` — 막과 이벤트별 장면 데이터
- `chg()` — 스탯 증감 (증감폭은 난수)
- `exec()` / `step()` — 진행 엔진

수치를 바꾸려면 `SEQ` 안의 `rnd(최소, 최대)` 와 각 선택지의 `cond` 만 고치면 됩니다.
